```html
<p><b>Cube Trainer</b> makes Rubik's Cube algorithm flashcards where the picture is generated from the algorithm.
Type the alg once and get the case diagram plus an animated solution. No screenshots, and the picture can never
disagree with the alg.</p>

<ul>
<li>Top-down (OLL sheet style), bottom and 3D views</li>
<li>Animated player: play, pause, step, speed, loop, tap a move to jump to it</li>
<li>Grey out pieces by stage: OLL, COLL, CMLL, F2L, cross</li>
<li>Any colour scheme, for example a green cross instead of white</li>
<li>Bundled CFOP sets: F2L (41), OLL (57), PLL (21), COLL (40) and 2-look OLL, sorted into sub-decks by case group</li>
<li>Import your own algs (<code>Name | alg</code> per line)</li>
<li>Cards sync to AnkiDroid and AnkiMobile. No internet needed</li>
</ul>

<p><b>Use:</b> Tools &gt; Cube Trainer &gt; Import algorithm sets. Change colours and views under Tools &gt; Cube Trainer &gt;
Settings, then sync.</p>

<p>Full documentation, source code and issue tracker: [link to your GitHub repository]</p>
```
